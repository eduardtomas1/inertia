published old/new npm package contents. The combined PR supersedes Dependabot

## Declined: better-sqlite3 13.2.0 (#770)

13.2.0 bundles the same SQLite 3.54.1 as the declined 13.1.1; its
`sqlite3.c` is byte-identical. `sqlite3_clear_bindings()` still expires a
statement whenever any re-preparation flag is set, and 13.2.0 still calls it
after every execution that binds parameters, so the slowdown measured on
2026-11-16 applies unchanged (history page 2.61 → 3.51 ms, message search
241 → 296 µs). No SQLite release after 3.54.1 changes
`sqlite3_clear_bindings()`.

13.2.0 also adds opening a database from a file descriptor and musl
detection through `/proc/self/maps`, which Inertia does not use.
`lib/binding.js` now prefers a compiled `build/Release/better_sqlite3.node`
over `prebuilds/`, where earlier versions preferred the prebuilds. Inertia
packages `build/Release/better_sqlite3.node` while the installer and
container smokes look for `prebuilds/<platform>-<arch>.node`, so a future
update must check which binary is loaded.
