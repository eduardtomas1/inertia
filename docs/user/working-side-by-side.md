# Working side by side

## Split view

Show up to four chats at once. Each pane keeps its own project, files, terminal, tools and draft.

### Add a chat

- Drag a chat from the sidebar onto the workspace. The half that will receive it lights up; release to split there.
- Or open the chat's actions and choose **Add this chat to split view**. It is disabled once four chats are showing.

A third chat splits the pane you drop it on, and a fourth completes a 2×2 grid.

### Rearrange

- Drag a chat that's already showing, or a pane's header by its grip, onto another pane's edge to move it there.
- If that edge can't split, the chat goes to the nearest edge that can. The two chats swap only when neither can.
- Press Escape, or release outside the window, to cancel a drag. A click that barely moves stays a click.

Each pane header lets you:

- open that chat in a new window,
- open or close its tools,
- **move it to the primary position**,
- **close the split chat**.

The second pane's header also has **Stack split chats** / **Place split chats side by side**, which flips the layout.

Every split has its own divider. Drag it, or focus it and use the arrow keys (2% per press, 5% with Shift), Home and End. Enter or a double-click resets it. Narrow windows stack the chats vertically.

In a two-chat split, selecting the second chat in the sidebar moves it to the primary position. Selecting a chat that's already in the third or fourth pane focuses that pane. To take a chat out of the split, close its pane or choose **Remove from split view** in its actions.

## Separate chat windows

Choose **Open chat in new window** in a chat's actions, or the window button in its pane header. The chat moves into its own window with its draft; up to eight chats can have their own windows at once. Choosing the chat again in the sidebar focuses its window.

A chat that has its own window can't be added to split view or dragged into it.
