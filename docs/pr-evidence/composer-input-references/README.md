# Composer input and draft chat references

Linux Electron screenshots from isolated test profiles with synthetic chats and
fixture providers. The user's app, profile, and provider sessions were not used.

- `composer-empty-dark.png`: the unsaved home-screen New chat, with its frame
  visible before focus.
- `composer-reference-light.png`: the same draft after attaching a chat and
  opening/closing its preview, retaining the typed message and painted frame.
- `composer-agents-dark.png`: a saved empty chat with the Agents panel open,
  matching the other reported layout.
- `chat-reference-confirmation.png`: explicit inline consent before sharing a
  chat across workspaces; Cancel is initially focused.

Generated by `tests/e2e/composer-entry.spec.ts` and
`tests/e2e/conversation-context.spec.ts`. The tests inspect rendered border
pixels, use actual mouse clicks and keyboard typing, and verify context reaches
the intended sent message. Computed CSS alone previously missed the vanished
pseudo-element frame.

These are source-build Linux checks, not packaged AppImage, native Windows/macOS,
or authenticated-provider certification.
