# Duo

A Duo sends the same brief to two agents at once, so you can compare approaches side by side.

## Launch a Duo

1. Choose **Launch two chats** in the sidebar, next to **New chat**.
2. Write the **Brief for both chats**.
3. Choose two ready model routes. Inertia only launches when both routes are available.
4. Optionally turn on **Compare with a third model** to add an independent judge. Its options show exactly what is shared with the judge, and whether the judge can edit a source checkout. A comparison needs three ready routes.

The two chats open side by side in [split view](working-side-by-side.md). When a comparison finishes, its chat opens so you can read the verdict.

## If something goes wrong

The Duo dialog reports dispatch and recovery status for each side, such as a start that failed or an outcome that couldn't be confirmed, and offers the recovery actions that apply.
