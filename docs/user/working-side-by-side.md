# Working side by side

## Split view

Open a second chat next to the current one from the sidebar: open the chat's actions and choose **Add this chat to split view**. Each pane keeps its own project, files, terminal, tools and draft.

Each pane header lets you:

- open that chat in a new window,
- open or close its tools,
- **move it to the primary position**,
- **close the split chat**.

Drag the divider to resize the panes, or focus it and use the arrow keys (2% per press, 5% with Shift), Home and End. Enter or a double-click resets the split. Narrow windows stack the chats vertically.

Selecting the split chat in the sidebar moves it to the primary position. To end the split, close the pane or choose **Remove from split view** in the chat's actions.

## Separate chat windows

Choose **Open chat in new window** in a chat's actions, or the window button in its pane header. The chat moves into its own window with its draft; up to eight chats can have their own windows at once. Choosing the chat again in the sidebar focuses its window.

A chat that has its own window can't be added to split view at the same time.
