# Visual campaign, before and after

Captures of the visual campaign on `feat/turn-feel-2026-10`. Before is commit 1a192a1e2 and after is commit dc262c278. Both sets come from one throwaway Playwright spec run against each packaged build with the same seeded projects, chats and turns, fake providers only and no DOM edits, so the build is the only difference.

AFTER turn footers appear on hover, so finished turns show no footer row in the after captures.
The browser-panel captures composite the native browser view onto the window capture at 1440×860, because the native view is not part of the page screenshot.
The 1440×920, 760×600 and 1920×1200 captures are viewports emulated by Playwright at device scale factor 1 inside a 1440×860 window, because the capture machine's screen cannot hold a larger window.
Clock times, relative ages and the running timer differ slightly between the two sets because they were captured at different times.

Each line names one before/after pair: surface, theme, size, then what to notice.
