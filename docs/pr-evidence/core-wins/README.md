# Core wins: tests and measurements

How each area of the core wins pull request is proven, what was measured and which documentation changed. Each area's screenshots are in its own folder next to this file. Renderer bundle numbers below were measured per area while the work landed; the final caps are the caps of main at 92822a26 plus the growth of the whole branch measured against a build of that commit.
