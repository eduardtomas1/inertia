## Integration findings and fixes

1. ACP imports move to `@agentclientprotocol/sdk/unstable` in source, tests
   and the provider drift scripts, so harness and session code share one
   `ClientContext` class. The drift probe keeps installing the package by name.
2. Provider capability manifests align their bundled versions and
   SDK-specific protocol identities with the exact pins: Claude 0.3.309,
   OpenCode 1.19.4, Cursor and Kimi 2.0.1 (still `acp-v1`).
3. The Windows installed-binary inventory drops `dxil.dll` (24 → 23 files) and
   asserts it stays out, as the Electron 44 update did for `libEGL` and
   `libGLESv2`.
4. The installer smoke test pins the reviewed electron-builder 26.18.0.
5. Renderer bundle budgets grow by the measured 115/115/110 bytes.
6. With the 0.3.310 follow-up, the Claude capability manifest pins 0.3.310.
