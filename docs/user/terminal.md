# Terminal

Each chat has terminals that run in the chat's folder: the project, or the chat's worktree when it has one. They are available after the chat's first message creates its workspace.

- **Dock or surface.** ⌘J (Ctrl+J elsewhere) shows or hides the terminal docked under the chat. Choose **Terminal** in the right panel's surface chooser (⌘G, then T) to open it as a surface instead.
- **Tabs.** **New terminal** adds a tab, up to four. Move between tabs with ← →, Home and End; Delete or a tab's close button ends that terminal.
- **Split.** **Split terminals** shows two terminals side by side, or stacked in a narrow panel. Drag the divider to resize it.
- **Session controls.** **Fit terminal** refits the terminal to its space, **Restart terminal** starts a fresh shell, and **Close terminal** ends it. **Hide terminal** hides it and keeps its terminals running.
- **Right-click** for **Copy**, **Paste**, **Select all**, **Add selection to prompt** and **Clear**. ⌘V pastes on macOS, Ctrl+V on Windows and Ctrl+Shift+V on Linux.
- **Find.** ⌘F on macOS, or Ctrl+Shift+F on Windows and Linux, while the terminal has focus, or **Find in terminal**, opens a find field over the output. Ctrl+F keeps reaching the shell and the programs running in it. Typing finds the next match as you go; Enter and **Next match** move forward, Shift+Enter and **Previous match** move back, and **No matches** shows when nothing is found. Clearing the field removes the highlight. Esc closes it and returns focus to the terminal.
- **Links.** Click an http or https address to open it in your browser, including links a program prints as clickable text. Other kinds of addresses are not opened. Click a file path, such as `src/app.ts`, `src/app.ts:12:3`, `src/app.ts(12,3)` or an absolute path inside the chat's folder, to open the file in **Files** at that line. A path such as `notes/copy(2)` that only looks like it ends in a line number opens that file when no `notes/copy` exists. Relative paths always resolve against the root of the chat's folder (the project, or the chat's worktree), not the shell's current folder: after `cd src`, a printed `app.ts` links only when `app.ts` exists at the root. A path becomes a link when you point at it only if the file exists inside the chat's folder; folders, missing files, paths outside the folder and symbolic links that lead outside it stay plain text.
- **Add selection to prompt.** Select output and choose **Add selection to prompt** from the tab row or the right-click menu to add it to this chat's message box as a fenced block headed with the terminal's name, ready to edit before you send. Up to the last 200 lines and 8 KiB are added; the heading says when the selection was shortened. When the chat's message box isn't open, for example because the chat is in its own window, the selection stays and the terminal says **Open this chat's message box to add the selection.**
- **Resume a provider chat.** Type `/resume` in the composer to open the terminal with **Resume chat**, which continues the chat's provider session in that provider's command-line tool. Choose another chat from the same folder when there is more than one. While a session is resumed there, end that terminal session before you send another message in Inertia. A session can be resumed in one tab at a time.
- **Project actions.** Actions you run from the header, such as a dev server or a check, start in a terminal tab.
